# AISTVM — Linux Cloud tức thì

Khởi chạy môi trường Linux trên cloud để học tập, kiểm thử và chạy lệnh từ xa
ngay trong ứng dụng AISTVM.

## Điểm nổi bật

- Máy Linux riêng cho từng phiên làm việc.
- Terminal thật (PTY) chia sẻ qua sshx.io: mở bằng link, không cần cài gì.
- Chạy lệnh trực tiếp trên trình duyệt, có thể chia sẻ cho người khác.
- Theo dõi thời gian chạy.
- Tự động dọn dẹp tài nguyên sau khi phiên kết thúc.
